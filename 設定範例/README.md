# 設定範例

`ris_gui.py` 實際讀的是專案根目錄下的 `設定/<院區名稱>/`，裡面放：

- `accounts.csv` — 代班帳號清單
- `doctors.csv` — 該院區合法的排班醫師帳號（用來過濾「改成」下拉）
- `mapping.csv` — 休假代班對照表（哪種班換成哪個帳號）
- `欄位選項.csv` — 各欄位下拉選單的合法值

因為裡面是真實院區的醫師姓名與帳號，`設定/` 整個資料夾不會進版控
（見 `.gitignore`）。這裡的 `範例分院/` 是格式示範（假資料），
要在自己的院區用，照這個格式在 `設定/<你的院區>/` 底下建立四個檔案，
可以用 `build_configs.py` 從 RIS 的傾印檔自動產生，也可以手動編輯。
